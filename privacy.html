Privacy Policy

Data KlipBot handles

  • Account tokens: OAuth access and refresh tokens for the operator's own YouTube, Instagram and TikTok accounts. They are stored only on the operator's computer and used only to publish videos and read the operator's account statistics.
  • Basic profile info: the account ID and display name returned by TikTok Login Kit (user.info.basic), used to confirm which account is connected.
  • Audience statistics: aggregated viewer country and language shares from the operator's own accounts, used to choose the language of new videos.
  • Public stream data: video, audio and chat messages from public live streams, processed to find and cut clips. Chat is used only as anonymous message counts and text; usernames are not stored. Temporary recordings are deleted within minutes.

Sharing

KlipBot does not sell or share personal data. Clip audio, frames and text are sent to AI services (speech-to-text runs locally; Anthropic's Claude API is used to evaluate clips and write captions) only to process the clip.

Deletion

The operator can disconnect any account by revoking access in that platform's settings, which makes the stored token unusable, and by deleting the local token file. Requests about data or removal of content: https://github.com/tahademirkama-svg/klipbot/issues.
